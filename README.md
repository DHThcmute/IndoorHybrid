TO USE THE CODE:

1. The main computer (Anchor L1) requires Linux OS in order to run.
2. Open Terminal, run: chmod +x run_master.sh && ./run_master.sh
3.1 Run all the other anchors on either Windows or Linux. If in Linux, open terminal and run: chmod +x run_anchor_ubuntu.sh && ./run_anchor_ubuntu.sh
3.2 If in windows, double click on run_anchor_windows.bat to run.

IN-APP OPERATIONS:

1. Run L1, then L2 and L3 and L4.
2. Install Sensor Logger, enable Accelerometer and Orientation.
3. Chose a fix angle and check the box use IMU as prior, choose a fixed angle for the phone and start the calibration.
4. After calibration, click on Build Hybrid Model and then Start Live to see the real-time estimated coordinates.
